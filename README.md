# Da'Vinci Burger

Página web de pedidos para la hamburguesería **Da'Vinci Burger**.

Diseño mobile-first con estilo retro.

## ¿Qué puedes hacer?

- Ver el menú de hamburguesas, perros calientes (hotdogs) y salchipapas
- Explorar los platos destacados en el carrusel principal
- Ver la foto real de cada producto
- Armar tu pedido en el carrito
- Enviar la orden por WhatsApp con tus datos de entrega y pago

## Cómo funciona

1. Eliges lo que quieres del menú
2. Lo agregas al carrito con el botón `+`
3. Revisas tu pedido en **VIEW CART**
4. Completas tu nombre, tipo de entrega y método de pago
5. Confirmas y se abre WhatsApp con el pedido listo para enviar

## Idea del proyecto

Una carta digital rápida y fácil de usar desde el celular, para pedir sin complicaciones y recibir la orden directo por WhatsApp.
